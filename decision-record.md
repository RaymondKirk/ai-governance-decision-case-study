# Sample decision record

**Fictional scenario. This record is unapproved and does not document a live release.**

| Field | Example entry |
| --- | --- |
| Decision | Conditional approval to prepare a limited pilot; launch remains blocked |
| Use case | Internal assistant over approved policy documents |
| Decision owner | Executive sponsor |
| Contributors | Product, operations, security, privacy, and employee representative |
| Date | To be entered after review |
| Evidence reviewed | Pending: document inventory, access tests, answer evaluation, vendor review, incident plan |
| Open risks | AI-01 through AI-06 in the risk register |
| Conditions | All launch gates in README must pass; no client or HR data in pilot |
| Expiry / review | At end of pilot or after a material model, data, or permission change |
| Final sign-off | Pending |

## Decision questions

1. Does the benefit justify using AI rather than improving search or documentation?
2. Can users see only material they already have permission to read?
3. What evidence shows safe handling of outdated and missing policy information?
4. Who can stop the pilot, and how quickly can access be removed?

If evidence is missing, the decision stays at **prepare pilot**, not **launch pilot**.
